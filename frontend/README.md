# OpsPilot Frontend

React SPA for the OpsPilot incident response workflow.

## Stack

- React
- TypeScript
- Vite
- React Router
- TanStack Query
- Tailwind CSS
- Vitest
- React Testing Library

## Scripts

```bash
npm run dev
npm run build
npm run test
npm run lint
```

## Initial Screens

- Dashboard
- Incidents
- Incident Detail
- Runbooks
- Analysis

The current implementation uses mock incident data until the Spring Boot API is available.
